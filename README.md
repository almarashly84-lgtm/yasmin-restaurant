# موقع مطعم ياسمين + لوحة التحكم

موقع مطعم شامي في فيينا بثلاث لغات (العربية، الألمانية، الإنجليزية)، مع لوحة تحكم كاملة.
يعمل على **Cloudflare Workers** مع قاعدة بيانات **D1** وتخزين صور **R2**.

## ماذا يوجد في الموقع

| القسم | ما يفعله |
|---|---|
| الواجهة | شعار ثلاثي الأبعاد يدور، وحوله المطابخ تدور. الضغط على مطبخ يفتح قائمته |
| المطابخ | السوري، الخليجي، المعجنات، الوجبات السريعة، كترينج الحفلات. كلها تُعدَّل من اللوحة |
| القائمة | أقسام وأصناف، صور، أحجام وأسعار، خصم، «نفد اليوم»، نباتي/حار/جديد |
| الكترينج | باقات، وطلب عرض سعر عبر واتساب (مع أقل عدد أشخاص) |
| الحجز | تاريخ ووقت وعدد أشخاص ومناسبة، والأوقات تُحسب من أوقات الدوام. يفتح واتساب برسالة جاهزة |
| الطلب (اختياري) | سلة طلبات للاستلام عبر واتساب، تُفعَّل من اللوحة |
| الصور | شريط صور سلس بالسحب، وعارض صور بملء الشاشة مع السحب بالإصبع |
| التقييمات | الزوار يكتبون تقييمهم، ولا يظهر إلا بعد موافقة المطعم. مع تقييم Google ورابطه |
| قانوني | Impressum و Datenschutz تُبنى من البيانات في اللوحة |

## لوحة التحكم `/admin`

التقرير السنوي (زيارات، فتح القوائم، حجوزات، كترينج، طلبات، اتصالات، تحميل CSV)، القائمة، الصور، التقييمات، الحجز والطلبات، معلومات المطعم وأوقات الدوام، Impressum، رموز QR، تغيير كلمة السر.

**الأمان:** كلمة السر مشفّرة (PBKDF2) · جلسة بـ Cookie محمي تنتهي بعد 7 أيام · قفل 15 دقيقة بعد 5 محاولات خاطئة · حماية من الطلبات القادمة من مواقع أخرى · كل البيانات تُفحص على السيرفر · النصوص تُعرض كنص فقط (لا XSS) · ملف CSV محمي من الصيغ · لا تُحفظ أسماء أو أرقام الزبائن في الإحصائيات.

## التشغيل لأول مرة

1. ارفع هذا المجلد إلى مستودع GitHub جديد.
2. أنشئ في Cloudflare قاعدة بيانات D1 باسم `yasmin-db` وتخزين R2 باسم `yasmin-images`، وضع `database_id` في `wrangler.jsonc`.
3. في Cloudflare: **Workers & Pages ← Create ← Import a repository** واختر المستودع.
4. في **Settings ← Variables and Secrets** أضف سرّين (Secret):
   - `ADMIN_INITIAL_PASSWORD` كلمة سر مؤقتة لأول دخول (تُغيَّر إجباريًا بعد الدخول).
   - `IP_SALT` نص عشوائي طويل.
5. افتح `/admin`، ادخل، غيّر كلمة السر، ثم املأ: رقم الواتساب، العنوان، الهاتف، Impressum، والصور الحقيقية.

## قبل النشر للعامة

- [ ] بيانات Impressum كاملة (اسم الشركة، المالك، العنوان، الهاتف، الإيميل، UID، GISA).
- [ ] رقم واتساب المطعم مضاف ومجرَّب.
- [ ] الصور الحقيقية بدل الرسومات المؤقتة.
- [ ] الأسعار والأصناف الحقيقية.
- [ ] تسجيل الموقع في Google Search Console وربطه بملف Google Business.

## للمطوّر

```bash
npm install
npx wrangler dev        # تشغيل محلي على http://localhost:8787 (أسرار التجربة في .dev.vars)
npm run check           # فحص HTML
```

ملفات `/assets/` و `/fonts/` تُحفظ في المتصفح سنة كاملة. عند تعديلها غيّر `?v=` في روابطها داخل ملفات HTML.
